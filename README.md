# Automatic File Organizer

**Author:** Soad17339-blip

A simple and efficient Python script that automatically organizes files in your Downloads folder into categorized subfolders based on file extensions.

## Features
- Organizes files into folders: **Images**, **Documents**, **Audio**, **Videos**, **Archives**, **Code**, **Executables**, and **Others**.
- Lightweight and fast.
- Uses built-in Python libraries (`os`, `shutil`) — no external dependencies needed.

## Usage
1. Download or clone the repository.
2. Run the script:
   ```bash
   python main.py
